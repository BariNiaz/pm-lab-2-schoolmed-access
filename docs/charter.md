## 3. Границы проекта
**Входит:**

- Сбор данных о школах и поликлиниках Уфы, включая их расположение на карте.
- Подготовка данных об улицах, дорогах и маршрутах города.
- Построение изохрон, показывающих, за какое время можно добраться до школ и поликлиник.
- Сравнение доступности учреждений в разных районах Уфы.
- Выявление районов, где жителям сложнее добираться до школ и поликлиник.
- Создание итоговой карты и отчёта с результатами исследования.

**Не входит:**

- Строительство новых школ и поликлиник.
- Изменение существующих маршрутов общественного транспорта.
- Разработка отдельного мобильного приложения.
- Анализ других городов и районов за пределами Уфы.
- Сбор личных данных жителей и медицинской информации.
- Практическое решение проблем с доступностью учреждений.

## 4. Допущения и ограничения
| **Тип** | **Описание** | **Как проверяем** |
|---|---|---|
| Допущение | В открытом доступе есть данные о расположении школ и поликлиник Уфы | Найти и проверить открытые источники |
| Допущение | Данные о дорогах и улицах города подходят для построения маршрутов | Проверить несколько маршрутов на карте |
| Допущение | Изохроны помогут наглядно сравнить доступность учреждений | Сравнить зоны доступности разных районов |
| Допущение | Для анализа достаточно открытых данных | Проверить доступность и полноту информации |
| Ограничение | Проект должен быть выполнен до конца учебного семестра | Следить за сроками в GitHub Projects |
| Ограничение | В команде работают 3 человека | Распределять задачи между участниками |
| Ограничение | Используются бесплатные сервисы и открытые данные | Проверять условия использования источников |
| Ограничение | Нет доступа к внутренним данным администрации и медицинских учреждений | Использовать только доступную публичную информацию |
