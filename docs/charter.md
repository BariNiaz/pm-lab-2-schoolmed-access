# Устав проекта: доступность школ и поликлиник в Уфе

Версия 1.2 · Дата: 15.11.2026 · Авторы: Нияз Бадриев, Виктория Исаева, Тимур Зайнуллин · Статус: базовый план утверждён

## 1. Проблема и ценность
Жителям Уфы сложно оценить реальную доступность школ и поликлиник: близкий по карте объект может быть далеко по времени в пути, а сравнивать районы неудобно. Нужно это родителям (время ребёнка до школы), жителям (дорога до поликлиники) и администрации (поиск районов с нехваткой объектов). Решение — карта Уфы с объектами и изохронами зон доступности пешком и на транспорте, что помогает сравнивать районы, находить проблемные зоны, ориентироваться жителям и планировать городу.
Бизнес-обоснование: [business-case.md](business-case.md)

## 3. Границы проекта

**Входит:**

- Сбор данных о школах и поликлиниках Уфы, включая их расположение на карте.
- Подготовка данных об улицах, дорогах и маршрутах города.
- Построение изохрон, показывающих, за какое время можно добраться до школ и поликлиник.
- Сравнение доступности учреждений в разных районах Уфы.
- Выявление районов, где жителям сложнее добираться до школ и поликлиник.
- Создание итоговой карты и отчёта с результатами исследования.

**Не входит:**

- Строительство новых школ и поликлиник.
- Изменение существующих маршрутов общественного транспорта.
- Разработка отдельного мобильного приложения.
- Анализ других городов и районов за пределами Уфы.
- Сбор личных данных жителей и медицинской информации.
- Практическое решение проблем с доступностью учреждений.

## 4. Допущения и ограничения

| **Тип** | **Описание** | **Статус после ЛР 2** |
|---|---|---|
| Допущение | В открытом доступе есть данные о расположении школ и поликлиник Уфы | Проверено: 163 школы и 178 поликлиник из OSM, см. [data-quality.md](data-quality.md) |
| Допущение | Открытых данных достаточно для первого анализа доступности | Проверено: достаточно с оговорками — [data-quality.md](data-quality.md) |
| Допущение | Данные о дорогах и улицах города подходят для построения маршрутов | Не проверено, проверяем при расчёте изохрон в ЛР 3–5 |
| Допущение | Изохроны помогут наглядно сравнить доступность учреждений | Не проверено, проверяем в ЛР 3–5 |
| Ограничение | Первый анализ считает расстояние по прямой, а не по пешеходной сети | Принято: реальный путь длиннее, выводы сопровождаются оговоркой |
| Ограничение | В OSM редко заполнены адреса и режим работы школ (11 % и 4 %) | Принято: карточки объектов на карте будут неполными |
| Ограничение | В слое медицинских объектов есть частные клиники и лаборатории | Лаборатории и центры исключены; доступность в центре может быть завышена |
| Ограничение | Население районов взято по переписи 2021 года | Используется только для показателя «на 10 тыс. жителей» |
| Ограничение | Проект должен быть выполнен до конца учебного семестра | Следим за сроками в GitHub Projects |
| Ограничение | В команде работают 3 человека, используются бесплатные сервисы и открытые данные, нет доступа к внутренним данным администрации | Распределяем задачи, проверяем лицензии, работаем только с публичной информацией |

## 8. Подход к управлению

Выбран гибридный подход: вехи и бюджет фиксируем заранее, а продукт делаем двухнедельными спринтами. Синхронизация команды — по четвергам в 20:00 на 30 минут, демонстрация результатов — в конце каждого спринта, изменения объёма — только через запрос на изменение. Обоснование выбора и альтернативы — [ADR-001](adr/ADR-001-lifecycle.md), правила команды — [team-agreement.md](team-agreement.md), доска — GitHub Projects. Базовый план: [оценки](estimation.md), [календарный план](schedule.md), [бюджет](budget.md), [план коммуникаций](communication-plan.md).

## 10. Предварительные критерии приёмки продукта

- карта открывается в браузере и показывает школы и поликлиники Уфы;
- для объектов строятся пешие изохроны 10, 15 и 20 минут;
- работают фильтры по району, типу объекта и времени доступности;
- в отчёте описаны не менее трёх районов с низкой доступностью и причины;
- источники данных и лицензии указаны в [data/sources.md](../data/sources.md);
- ноутбуки сохранены без вывода ячеек, расчёты воспроизводимы по инструкции;
- карта и документация опубликованы на GitHub Pages.
