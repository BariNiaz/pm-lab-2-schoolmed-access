
# Definition of Ready и Definition of Done

## Definition of Ready (задача готова к работе)

Задачу можно брать в работу, если:

- [ ] У задачи есть понятное название и описание ожидаемого результата.
- [ ] Указаны проверяемые критерии приёмки, на которые можно ответить «да» или «нет».
- [ ] Задача привязана к одному из эпиков E1–E6.
- [ ] Указаны связанные требования FR, NFR, DR или пакет WBS, если они есть.
- [ ] Назначен ответственный за выполнение задачи.
- [ ] Указаны необходимые зависимости и связанные задачи.
- [ ] Для пользовательской истории указан приоритет MoSCoW.
- [ ] Команда понимает, какие действия необходимо выполнить для получения результата.
- [ ] Оценка трудозатрат соответствует возможностям команды и срокам проекта.

## Definition of Done (задача выполнена)

### Для любой задачи

- [ ] Все критерии приёмки задачи выполнены.
- [ ] Получен конкретный результат, указанный в описании задачи.
- [ ] Результат проверен ответственным участником команды.
- [ ] Изменения в документах и коде сохранены в репозитории.
- [ ] Если изменялись файлы репозитория, создан Pull Request.
- [ ] Pull Request проверен и одобрен минимум одним другим участником команды.
- [ ] Все проверки, предусмотренные для задачи, пройдены без ошибок.
- [ ] В документации нет незаполненных обязательных разделов и пометок TODO.
- [ ] Для использованных внешних данных и фактов указаны источники.
- [ ] При использовании ИИ информация об этом внесена в `docs/ai-usage.md`.

### Для задач с данными

- [ ] Для каждого набора данных указан источник.
- [ ] Для каждого набора данных указаны дата получения и условия использования, если они доступны.
- [ ] Для данных указана лицензия или условия использования, если они опубликованы.
- [ ] У каждого объекта, для которого это предусмотрено схемой данных, есть название и координаты.
- [ ] Проверены пропущенные значения и дубликаты.
- [ ] Координаты проверены на соответствие фактическому расположению объектов.
- [ ] Система координат указана и соответствует выполняемым пространственным расчётам.
- [ ] Сырые и обработанные данные хранятся раздельно.
- [ ] Обработанные данные сохранены в согласованном формате.
- [ ] Результаты проверки качества данных записаны в `docs/data-quality.md`.
- [ ] Другой участник команды может повторить обработку данных по инструкции.

### Для пользовательских историй

- [ ] Все сценарии из критериев приёмки проверены.
- [ ] Каждый критерий приёмки выполнен.
- [ ] Реализован пользовательский сценарий, описанный в истории.
- [ ] Связанные функциональные требования FR выполнены.
- [ ] Связанные нефункциональные требования NFR проверены.
- [ ] Результат отображается корректно на карте, если история связана с картой.
- [ ] Для отображаемых данных указаны источники и присутствует понятная легенда, если это необходимо.
- [ ] Результат продемонстрирован команде.
- [ ] Обнаруженные ошибки и замечания записаны в отдельные задачи GitHub.
